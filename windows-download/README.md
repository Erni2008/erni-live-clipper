# ERNI Live Clipper

Desktop-приложение для стримеров: во время live быстро ставишь таймкод-метки в TXT, а после стрима скачиваешь нужные диапазоны из сохраненной трансляции.

Используй приложение только для своих трансляций или контента, на который у тебя есть разрешение.

## Что умеет

- Подключается к live-ссылке через `yt-dlp`.
- Имеет первую вкладку `Stream Markers`: отслеживает текущий live-таймкод и пишет смешные моменты в TXT.
- Записывает в TXT ссылку на стрим, дату, таймкод метки и готовый диапазон `From -> To`.
- Скачивает выбранный диапазон live напрямую, без записи всего стрима, если платформа дает DVR/перемотку.
- Умеет записывать лучший доступный поток в локальный master-файл как fallback.
- Не ограничивает длину клипа, ограничение только по свободному месту на диске.
- Делает быстрые live-клипы через кнопки и горячие клавиши.
- Поддерживает глобальные хоткеи на Windows через `pynput`; на macOS рабочий набор `Ctrl + Option + 7`, `F7`, `Ctrl + Option + M` и `Ctrl + Option + 1/2/3/4`.
- Имеет вкладку `Saved Video Range` для законченных стримов/обычных видео: вставляешь ссылку и скачиваешь только диапазон `From - To`.
- Поддерживает теги клипов: `funny`, `rage`, `fail`, `win`, `shorts`, `important`.
- Поддерживает пустой по умолчанию комментарий к клипу.
- Складывает клипы по папкам `clips/YYYY-MM-DD/tag`.
- Ведет CSV-лог клипов: `clips/clips_index.csv`.
- Открывает готовый клип через `Preview selected`.
- Улучшенная доступность: крупные кнопки, фокус с клавиатуры, подсказки, высокий контраст.
- Ставит клипы в очередь, если нажать несколько моментов подряд.
- Поддерживает ручной диапазон `00:07:00 - 00:08:00`.
- Поддерживает быстрые кнопки `last 30s`, `last 60s`, `last 3m`, `last 5m`.
- Поддерживает хоткеи `F8`, `F9`, `F10`, `F11`, `Cmd + Enter`, `Esc`.
- Есть отдельный блок `Exact range`: вводишь `From` и `To`, приложение скачивает ровно этот кусок.
- Экспортирует в двух режимах:
  - `Original Fast` - быстро, без перекодирования.
  - `Universal Editing MP4` - H.264 + AAC + CFR + yuv420p + 48 kHz stereo.
- Проверяет готовый клип через `ffprobe`.
- Показывает лог команд и ошибок внутри приложения.

## Требования

На macOS:

```bash
brew install yt-dlp ffmpeg
```

На Windows:

```powershell
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

Для сборки `.exe` смотри `WINDOWS_BUILD.md`. Windows-скрипт по умолчанию делает быстрый portable-билд и сам добавляет `yt-dlp`, `ffmpeg`, `ffprobe` внутрь сборки.

## Windows-сборка

На Windows открой PowerShell в папке проекта и запусти:

```powershell
.\build_windows.ps1
```

Готовая portable-версия:

```text
dist\ERNI Live Clipper\ERNI Live Clipper.exe
```

Готовый ZIP:

```text
dist\ERNI Live Clipper Windows.zip
```

Если нужен один файл, можно собрать медленнее запускающийся `.exe`:

```powershell
.\build_windows.ps1 -OneFile
```

## Запуск из исходников

```bash
cd erni-live-clipper
python3 app.py
```

## Как пользоваться

1. На первой вкладке `Stream Markers` вставь ссылку на live-стрим.
2. Выбери папку сохранения.
3. Нажми `Start Tracking`.
4. На смешном моменте нажми `Ctrl + Option + 7` на macOS / `Ctrl + Alt + 7` на Windows.
5. После стрима открой TXT через `Open TXT`.
6. Скопируй ссылку и диапазон `From -> To` во вкладку `Saved Video Range`, чтобы скачать клип из законченной трансляции.

## Качество live

Приложение берет максимальное качество, которое YouTube отдает внешнему загрузчику `yt-dlp`. Если YouTube отдает 1080p, клип будет 1080p; если отдает 1440p, приложение выберет 1440p.

## Готовый стрим или обычное видео

1. Открой вкладку `Saved Video Range`.
2. Вставь ссылку на уже завершенную трансляцию или обычное видео.
3. Введи диапазон, например `From = 01:44:18`, `To = 01:46:12`.
4. Нажми `Download Saved Video Range`.
5. Приложение скачает только этот фрагмент в максимальном доступном качестве.

## Горячие клавиши

Подробная документация лежит в `HOTKEYS.md`.

- `F7` - записать текущий live-таймкод в TXT на вкладке `Stream Markers`.
- `Ctrl + Option + 7` - основной глобальный хоткей TXT-метки на macOS.
- `Ctrl + Option + M` - запасная TXT-метка на macOS.
- `Ctrl + Alt + 7` - основной глобальный хоткей TXT-метки на Windows.
- `Ctrl + Alt + M` - TXT-метка на Windows.
- `F8` - скачать последние 30 секунд live.
- `F9` - скачать последние 60 секунд live.
- `F10` - скачать последние 3 минуты live.
- `F11` - сделать клип вокруг текущей записи или значения `To`.
- `Cmd + Enter` - скачать ручной диапазон `From - To`.
- `Ctrl + Option + 1/2/3/4` - рабочие глобальные бинды на macOS.
- `Ctrl + Alt + 1/2/3/4` - глобальные бинды на Windows.
- `Cmd + L` - перейти в поле ссылки.
- `Cmd + O` - открыть папку сохранения.
- `Esc` - отменить текущий экспорт.

На macOS для глобальных хоткеев может понадобиться разрешение Accessibility. На Windows они обычно работают сразу.

## Важный принцип

Основной режим скачивает только выбранный кусок live. `Start Capture` оставлен как fallback для стримов, где платформа не дает нормально перематывать live назад.
