# ERNI Live Clipper Hotkeys

Горячие клавиши на macOS работают через несколько слоев. Самый надежный набор на Mac: `Ctrl + Option + 7` для TXT-метки и `Ctrl + Option + 1/2/3/4` для клипов.

На Windows доступны глобальные хоткеи через `pynput`: `Ctrl + Alt + 7`, `F7`, `Ctrl + Alt + M` и `Ctrl + Alt + 1/2/3/4`.

## Stream Markers

Это первая вкладка и основной сценарий для монтажа после стрима.

1. Вставь ссылку на live.
2. Нажми `Start Tracking`.
3. Когда случился смешной момент, нажми `Ctrl + Option + 7` на macOS / `Ctrl + Alt + 7` на Windows. Запасные варианты: `F7` или `Ctrl + Option + M` / `Ctrl + Alt + M`.
4. Приложение запишет метку в TXT: ссылка на стрим, дата, текущий таймкод и готовый диапазон `From -> To`.
5. После окончания стрима открой TXT, скопируй ссылку и диапазон во вкладку `Saved Video Range`.

Файл меток лежит в:

```text
markers/stream_markers_YYYY-MM-DD.txt
```

Хоткеи для меток:

- `F7` - записать текущий live-таймкод в TXT.
- `Ctrl + Option + 7` - основной глобальный хоткей на macOS, работает даже когда приложение свернуто.
- `Ctrl + Option + M` - запасной глобальный хоткей на macOS.
- `Ctrl + Alt + 7` - основной глобальный хоткей на Windows.
- `Ctrl + Alt + M` - глобальный хоткей на Windows.

Для свернутого режима на macOS приложению нужно разрешение Accessibility. После выдачи разрешения полностью перезапусти приложение.

## Быстрые клипы

- `F8` - скачать последние 30 секунд live.
- `F9` - скачать последние 60 секунд live.
- `F10` - скачать последние 3 минуты live.
- `F11` - сделать `Mark moment`: клип вокруг текущей записи или значения `To`.
- `Cmd + 1` / `Ctrl + 1` - скачать последние 30 секунд.
- `Cmd + 2` / `Ctrl + 2` - скачать последние 60 секунд.
- `Cmd + 3` / `Ctrl + 3` - скачать последние 3 минуты.
- `Cmd + 4` / `Ctrl + 4` - скачать точный диапазон из блока `Exact range`.
- `Ctrl + Option + 1/2/3/4` - запасные глобальные бинды для macOS.
- `Ctrl + Alt + 1/2/3/4` - глобальные бинды для Windows.

После нажатия хоткея в шапке приложения появится `Last hotkey: ...`, а в логе будет `Hotkey fired: ...`.

## Ручной диапазон From-To

1. В поле `From` введи начало клипа, например `00:25:00`.
2. В поле `To` введи конец клипа, например `00:25:15`.
3. Нажми `Download Exact Range`.

Пример: `From = 00:25:00`, `To = 00:25:15` скачает ровно `00:25:00 - 00:25:15`.

## Законченный стрим или обычное видео

1. Открой вкладку `Saved Video Range`.
2. Вставь ссылку на сохраненную трансляцию или обычное видео.
3. Введи `From` и `To`, например `01:44:18` -> `01:46:12`.
4. Нажми `Download Saved Video Range`.

Этот режим скачивает только выбранный фрагмент готового видео, не весь ролик.

## Ручной диапазон

- `Cmd + Enter` - скачать диапазон из полей `From` и `To`.
- `Ctrl + Enter` - то же самое для Windows/Linux.
- `Cmd + L` / `Ctrl + L` - перейти в поле ссылки.
- `Cmd + O` / `Ctrl + O` - открыть папку сохранения.

## Отмена

- `Esc` - отменить текущую загрузку/экспорт клипа.

## Доступность

- Основные кнопки крупные и доступны через Tab.
- При наведении или фокусе на кнопках появляются подсказки.
- Статус глобальных хоткеев виден в правой части шапки приложения.
- Для лучшей читаемости используется высококонтрастная темная тема.

## Как это использовать на стриме

1. Вставь ссылку на YouTube live.
2. Выбери папку сохранения.
3. Оставь режим `Universal Editing MP4`, если потом монтируешь в Premiere, DaVinci, VEGAS, CapCut или Final Cut.
4. Когда случился момент, нажми `Ctrl + Option + 1`, `Ctrl + Option + 2` или `Ctrl + Option + 3` на macOS. На Windows: `Ctrl + Alt + 1/2/3`.
5. Если нажал несколько раз подряд, клипы попадут в очередь и скачаются по одному.

## Теги и комментарии

- Тег выбирается кнопками `funny`, `rage`, `fail`, `win`, `shorts`, `important`.
- Если тег не выбран, клип попадет в папку `untagged`.
- Поле `Comment` пустое по умолчанию. Его можно заполнять перед клипом, чтобы потом проще монтировать.
- Все клипы записываются в CSV-лог `clips/clips_index.csv`.

## Папки

Файлы сохраняются так:

```text
clips/YYYY-MM-DD/tag/file.mp4
```

Пример:

```text
clips/2026-06-10/funny/2026-06-10_21-30-00_funny_00-20-00_00-20-30.mp4
```

## Важно

Если глобальные хоткеи не сработали, активируй окно приложения и используй те же клавиши внутри него. Если и внутри окна нет строки `Hotkey fired`, значит macOS или другая программа забрала сочетание; используй запасные `Ctrl + Option + 1/2/3/4` или `F8/F9/F10/F11`.
